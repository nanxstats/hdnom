# Plot model comparison by calibration results

Plot model comparison by calibration results

## Usage

``` r
# S3 method for class 'hdnom.compare.calibrate'
plot(
  x,
  xlim = c(0, 1),
  ylim = c(0, 1),
  col.pal = c("JCO", "Lancet", "NPG", "AAAS"),
  ...
)
```

## Arguments

- x:

  An object returned by
  [`compare_by_calibrate`](https://nanx.me/hdnom/reference/compare_by_calibrate.md).

- xlim:

  x axis limits of the plot.

- ylim:

  y axis limits of the plot.

- col.pal:

  Color palette to use. Possible values are `"JCO"`, `"Lancet"`,
  `"NPG"`, and `"AAAS"`. Default is `"JCO"`.

- ...:

  Other parameters (not used).
