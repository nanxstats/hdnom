# Plot external calibration results

Plot external calibration results

## Usage

``` r
# S3 method for class 'hdnom.calibrate.external'
plot(
  x,
  xlim = c(0, 1),
  ylim = c(0, 1),
  col.pal = c("JCO", "Lancet", "NPG", "AAAS"),
  ...
)
```

## Arguments

- x:

  An object returned by
  [`calibrate_external`](https://nanx.me/hdnom/reference/calibrate_external.md).

- xlim:

  x axis limits of the plot.

- ylim:

  y axis limits of the plot.

- col.pal:

  Color palette to use. Possible values are `"JCO"`, `"Lancet"`,
  `"NPG"`, and `"AAAS"`. Default is `"JCO"`.

- ...:

  Other parameters for `plot`.
