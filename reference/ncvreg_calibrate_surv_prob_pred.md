# Compute ncvreg predicted survival probabilities for calibration

Compute ncvreg predicted survival probabilities for calibration

## Usage

``` r
ncvreg_calibrate_surv_prob_pred(
  x_tr,
  x_te,
  y_tr,
  model.type,
  alpha,
  lambda,
  gamma,
  pred.at
)
```

## Value

list containing predicted survival probability
